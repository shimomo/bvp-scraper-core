## 📦 Requirements
- php: ^8.2
- bvp/converter: ^5.3
- bvp/trimmer: ^5.3
- symfony/browser-kit: ^6.0 || ^7.0
- symfony/css-selector: ^6.0 || ^7.0
- symfony/http-client: ^6.0 || ^7.0

## 💾 Installation
```bash
composer require bvp/scraper-core
```
